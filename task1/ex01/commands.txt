===
Название: ncdu  
Описание: Утилита для анализа использования дискового пространства в терминале.  
Синтаксис: ncdu [опции] [каталог]  
Пример: ncdu /home/user  
Примечание: Позволяет быстро находить, какие каталоги занимают больше всего места.

===
Название: bat
Описание: Современная альтернатива cat с подсветкой синтаксиса и нумерацией строк.  
Синтаксис: bat [опции] [файл] 
Пример: bat main.cpp
Примечание: bat может быть занято другим инструментом и вместо bat может работать batcat

===
Название: whoami
Описание: выводит имя текущего пользователя под которым выполняются команды
Синтаксис: whoami
Пример: 
    root@LAPTOP-484JFQUQ:/mnt/d# whoami
    root
Примечание: подобного результата можно добиться при помощи команды echo $USER

===
Название: history
Описание: Команда history показывает список ранее введённых команд в текущем терминале и позволяет повторно выполнять их без повторного ввода.
Синтаксис: history [опции]
Пример: 
    history 10 — покажет последние 10 команд из истории.
Примечание: можно повторно вызвать команду используя !<номер команды>

===
Название: top
Описание: Отображает список процессов в реальном времени с загрузкой CPU и памяти
Синтаксис: top [опции]
Пример: top -o %CPU
Примечание: Есть возможность сортировки по памяти или CPU

===
Название: !!
Описание: Двойной восклицательный знак !! в Bash служит для повторного выполнения предыдущей команды, введённой в терминале.
Синтаксис: !!
Пример: 
    root@LAPTOP-484JFQUQ:/mnt/d# whoami
    root
    root@LAPTOP-484JFQUQ:/mnt/d# !!
    whoami
    root

===
Название: vmstat
Описание: Показывает информацию о памяти, CPU и тд
Синтаксис: vmstat [интервал] [количество]
Пример: vmstat 2 5
Примечание: Полезно для диагностики

===
Название: cowsay  
Описание: Выводит текст «речью» ASCII-коровы или другого персонажа.  
Синтаксис: cowsay [опции] [текст]  
Пример: cowsay -f tux "hello worls"  
Примечание: Есть и другие животные (и сыр)

===
Название: sl  
Описание: Шуточная программа, показывающая анимацию паровоза.  
Синтаксис: sl [опции]  
Пример: sl -a 
Примечание: Может быть с аварией и летать

===
Название: cmatrix  
Описание: Симуляция падающего кода из фильма «Матрица».  
Синтаксис: cmatrix [опции]  
Пример: cmatrix -C green  
Примечание: Отличная заставка для терминала, особенно с зелёным цветом.
